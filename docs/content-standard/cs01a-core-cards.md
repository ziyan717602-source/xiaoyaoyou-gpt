# CS01A 核心四牌逐模式合同

状态：pass

## 为什么仍是 partial

旧版把同一张牌分成普通行动、事件带入、濒死救援、【净衣咒】和其他技能联动等多个入口。只完成其中一个入口不能把目录项标为 verified。CS01A 因此先冻结四张牌的模式边界，并把尚未存在的上游系统写成显式依赖：天雷破的事件目标模式属于 CS04；冰心诀对其余技牌、战牌、特殊牌和技能的覆盖随对应内容切片闭合；鼠儿果和灵葫仙丹的【净衣咒】联动属于 CS02。

## 已冻结规则

- 鼠儿果：行动阶段指定一名仍存活的可选玩家（可以是自己）；先支付卡牌并开放响应，无人抵消后目标补两张。
- 天雷破：普通模式指定一名仍存活的可选玩家，响应通过后造成 2 点雷属性伤害。旧 C# 另有事件直接提供目标的 type 1 入口，留给事件系统但已在合同中锁定。
- 冰心诀：当前响应优先权玩家可以让等待中的牌效果无效；冰心诀也可被另一张冰心诀抵消，按嵌套奇偶恢复父窗口。旧版 `IsTPOpt` 是玩家是否跳过对队友响应的提示偏好，不缩小服务端合法动作全集。
- 灵葫仙丹普通模式：仅当前行动者对自己使用，回复 2 点且不超过上限；旧 C# `TP02Valid(type 0)` 恒真，因此满血仍可支付并进入正常响应链。被冰心诀抵消时不回复。
- 灵葫仙丹救援模式：濒死窗口当前优先权玩家可令当前 0 HP 目标回复 2 点，然后继续同一濒死批次；这一模式不改写为普通行动响应窗口。
