# CS03-03B-02-PETS：NJ07 与宠物生命周期

契约：`contracts/pet-effects.contract.json`。这是 NJ01/NJ07 聚合节点的宠物前置部分；正式回合仍等待完整 NPC 与怪物分支，不改变范围目录的未完成状态。

## 可执行行为

- NJ07 由当前行动玩家依次选择交宠物者、其另一名活队友、交出的宠物。交宠物者可以是敌队成员，但接受者必须与交宠物者同队。三步都归当前玩家，与 NJ06 最后由交出者选牌不同。
- 没有同属性冲突时直接转移；有冲突时强制互换，不产生保留旧宠物窗口，也不弃掉其中一张。这是 `NC303.cs:184-236` 和 `Kitty.cs:10-268` 的 KOKAN，不是捕获新宠物的 ACTIVE 保留机制。
- 所有选择走 `submit-choice`、Actor、事件和系统期限。每次 15 秒，强制超时从合法 canonical ID 排序中种子随机；已自动座位在开启瞬间执行。断线不延期。
- 获得/失去的被动差额更新真实 STR/DEX，保留角色技能与其它既有修正。重复应用相同归属不重复加成。只支持当前范围的五行唯一槽位，拒绝重复宠物或同属性冲突。

## 死亡、顺序和恢复

`XIG.cs:389-410` 的 G0ZW 清理按每名死者先宠物、后同伴；宠物按 `FiveElement.cs` 的水、火、雷、风、土槽位顺序，而非代码字符串顺序。正常死亡与 JN50203 遗物分配均使用此清理；宠物／同伴不进入手牌遗物。当前未归属的正在结算 NPC 仍等待子效果结束。

schema 9 曾保存宠物归属但没有实际获得／失去被动。迁移到 10 时仅补一次被动及武器原因，保留选择、时间、NPC 续算、牌堆和 RNG。再次 JSON 恢复不叠加；损坏选择参与者、同队关系、槽位、重复实体、截止或原因会被拒绝。
