# CS01B 行动技牌合同

状态：进行中；JP03 已验证，JP01 普通手牌模式已验证但受保护牌联动待 CS02，JP02/JP06 待实现。

## 冻结规则

- 偷盗：只能选择另一名仍存活且至少有一张未受保护手牌的玩家。客户端只看到该目标的匿名手牌槽，最终转移由服务端按槽位对应的真实实例执行。
- 窥测天机：怪物牌堆至少一张时可用；查看顶部最多两张，两张时可以换序，一张时只查看。它依赖 CS03 的怪物牌堆，不能用行动牌堆临时代替。
- 五气朝元：主模式对施放者一方所有仍存活角色各回复 1 点，水属性归因，不超过体力上限；即使全部满血仍可支付。冰心诀可抵消整个效果。独立“典当”模式弃置此牌并补一张，不进入冰心诀响应链。
- 铜钱镖：选择一名具有未受保护手牌或装备的仍存活玩家，再选择其一张牌弃置。对手手牌必须匿名，装备公开；可以选择自己。

## 只读旧版证据

- 数据库 `Tux` 的 JP01/JP02/JP03/JP06 行提供说明、目标与“典当”文本；公开仓库不包含数据库本体。
- `JP06.cs:294-316`：偷盗排除自己与受保护牌，先选玩家，再以匿名槽选一张手牌并转移。
- `JP06.cs:318-327`：窥测天机根据怪物牌堆数量查看一或两张并允许两张换序。
- `JP06.cs:330-335`：五气朝元选择所有仍存活队友并造成 1 点水属性治疗。
- `JP06.cs:365-412`：铜钱镖可选手牌或装备，对隐藏手牌使用匿名项，受保护牌不可选。
- `ContentRule.cs:189-196`：五气朝元默认典当价值为一张补牌。

## 当前实现边界

- 偷盗在响应通过后创建仅施放者可见的强制选择；选项固定为 `opaque-hand-slot-N`，没有任何真实卡牌 ID。服务端重启后槽位保持一致，提交后才在服务端把槽位解析为目标当前手牌实例并转移。15 秒未选择时使用持久化 RNG 随机槽位；已进入自动模式的玩家立即执行该随机选择。
- 冰心诀抵消偷盗时不会创建手牌选择。目标与施放者相同、目标没有手牌、伪造槽位、错误玩家和过期输入均拒绝。
- 旧 C# 的 `ProtectedTux` 来自后续技能/效果系统；当前没有可产生受保护牌的内容，因此 JP01 保持 partial，等 CS02 建立保护来源后补排除回归，不误标整项 verified。

机器可读版本见 `contracts/action-tricks.contract.json`。
