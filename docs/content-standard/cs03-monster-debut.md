# CS03-03C-01：真实怪物登场结算

本节点实现六类登场行为及其伤害子流程；不代替战牌、胜败、捕获、消耗或正式回合。完整范围仍由 `GOAL_ACCEPTANCE.md` 决定。

## C# 证据与结果

证据等级为源码与已核验 SQLite 元数据的一致结论，不宣称黑盒等价。

| 怪物 | 登场效果                                                         | 主要证据                              |
| ---- | ---------------------------------------------------------------- | ------------------------------------- |
| GS01 | 行动者与存活妨碍者交换整手，保持牌序、无随机；旁观席只得手牌数量 | `FG04.cs:80-89`、`XIG.cs:1162-1205`   |
| GH03 | 有效支援者承受行动者当前战力减一的火伤害；非正数不造成伤害       | `FG04.cs:228-236`                     |
| GH04 | 所有存活玩家同时承受两点火伤害                                   | `FG04.cs:280-283`                     |
| GL02 | 有效支援者本场战力加二，不改写常驻角色属性                       | `FG04.cs:318-322`、`XIG.cs:2078-2112` |
| GT02 | 未参战且有手牌的存活玩家，按各自手牌数承受土伤害                 | `FG04.cs:618-624`、`Board.cs:182-186` |
| GT03 | 本场持有的怪物战力加三                                           | `FG04.cs:634-640`、`XIG.cs:2234-2253` |

`XIR.cs:455-508` 的 Z1→CC→ZC→ZD 把登场放在战牌前，并在 ZC 复制本场数值。其余十四只范围内怪物没有登场处理器；仍生成明确的战斗续算状态，但不因此跳过其胜败等后继效果。

GS01 的 C# 条件是 `IsAlive`，不是 `IsValidPlayer`。`ContentRule.cs:210` 的宠物参战者经 `Player.Warriors` 构造，`Player.cs:527-535` 明确令其 `IsAlive=false`，所以宠物妨碍不会交换主人的手牌。GT02 的宠物参战也不自动豁免主人。额外助战者的生产者仍属于后继战牌节点，不能用当前三种参战角色覆盖未来所有助战情况。

## 状态、伤害和恢复

- `encounterState.battle` 保存怪物身份、稳定登场效果身份、起始时间、最后推进时间、战斗临时属性及伤害来源父子表。
- 三个状态为 `debut-damage`、`combat-ready`、`aborted`。未结束的响应、追打、救援、死亡后选择或伤害不能进入 `combat-ready`。
- 怪物伤害使用独立 `sourceMonsterId`，`sourcePlayerId=null`，实际元素与 `from-nmb`；来自 `FG04.cs:3506-3535`。追打与死亡后自伤仍归因于实际技能玩家，通过来源父子表保留它们属于本次战斗的关系，不伪装成怪物直接伤害。
- 隐蛊（TP03）和冰心诀（TP01）沿用既有效果栈，救援沿用真实濒死批次；重启不重新打开窗口，不改变十五秒期限。自动玩家按原自动模式立即放弃，且不消费 RNG。
- 角色死亡但双方仍有存活者时，保留本场战斗继续执行；全局胜负已产生时，仅把持有怪物弃置一次，不发奖励。`XIR` 的登场后仍接战牌，回合末再处理死亡行动者，不新增隐式中断规则。
- JN30201 的实际追打目标包含原批次中受伤的自己；按 `XJ405.cs:626-636` 保持此行为。JN50501 的实际角色是 XJ405，JN50203 是 XJ402，不能用技能数字猜角色编号。

schema 从 11 升到 12。真实 v11 NPC 选择快照仅新增 `battle:null`，选择、牌区、RNG、期限不变。当前 schema 拒绝孤立战斗、循环伤害来源、错误怪物/效果、未完成子流程却标记就绪以及延长期限等损坏数据。事件重放重新计算登场结果，拒绝篡改报告。

## 投影和入口

没有客户端“选择怪物”“宣布胜负”或“开始登场”命令。内部 `beginMonsterDebut` 只能消费当前已持有的怪物，重复开始拒绝。根级 `availableActions` 继续提供真实响应/救援动作；`combat-ready` 暂不暴露未实现战牌动作。

玩家视图只包含公开怪物/阶段/临时数值和各自有权获得的牌。整手交换不向其他四席输出牌身份；不同私密手牌但相同数量的两个世界，不改变他人的动作、窗口或期限。
