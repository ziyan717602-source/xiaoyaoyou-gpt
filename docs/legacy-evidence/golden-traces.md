# 旧版规范化黄金轨迹

旧服务端的 TCP 握手、六连接可见性和选角广播已经由 `npm run oracle:protocol-smoke` 实机验证。指定规则场景使用源码派生、确定性归一化轨迹：

| 轨迹                      | 步数 | 等级 | 固定语义                                                   |
| ------------------------- | ---: | ---- | ---------------------------------------------------------- |
| `legacy-basic-turn`       |   13 | B    | R1 阶段推进、BC 补牌、ED 清理并进入 R2/00                  |
| `legacy-bingxin-response` |    4 | B    | TP01 响应当前技牌，消耗响应牌，原效果取消且不改变目标状态  |
| `legacy-dying-rescue`     |   14 | B    | 同时 0 HP、逐目标救援、TP02 回复、全员放弃后死亡、胜负重算 |

运行：

```powershell
npm run oracle:golden-traces
```

验证器会执行严格 JSON Schema、目录内容 ID、步骤证据索引、六人状态不变量和最终状态比较。本地参考快照存在时，还会验证每个 C# 来源文件的 SHA-256；公开克隆没有参考快照时仍可重放规范化状态机。

轨迹不复制旧规则描述文本。每一步只记录规范化输入/状态变化、来源文件行号、文件哈希和简短证据主张。旧程序的随机座次、抽牌和并发日志次序均明确排除在比较面之外。
