# P08 威胁模型

范围：匿名邀请码房间、六个玩家浏览器、单实例服务和 SQLite。无账号、观战、聊天、商城或管理员在线观战。

| 资产/威胁  | 主要攻击                   | 冻结控制                                                                                          | 验证方式                               | 剩余风险                                                      |
| ---------- | -------------------------- | ------------------------------------------------------------------------------------------------- | -------------------------------------- | ------------------------------------------------------------- |
| 座位身份   | 猜邀请码后冒用座位         | 建房/入座时产生 256-bit 随机 bearer；数据库只存 SHA-256；首帧认证，5 秒失效；新连接替换同座旧连接 | 无 token、错 token、跨座位包络集成测试 | 玩家主动泄露 token 等于转交座位                               |
| 命令权威   | 越权、重放、重复、乱序     | 认证座位绑定；`commandId` 收据；`clientSequence`；`expectedVersion`；`availableActions` 校验      | 六连接失败矩阵、属性测试、原子事务测试 | DoS 仍可消耗校验资源                                          |
| 私密状态   | 手牌/响应能力/种子泄漏     | 每接收者重新投影；无观战；错误同形；禁止共享对象原地脱敏                                          | 六投影属性测试、协议/E2E 侧信道场景    | 复杂时序侧信道需持续回归                                      |
| 重连令牌   | URL、代理或日志泄漏        | token 不进 query/header 日志；只在 WS 首帧；Pino 明确 redact；业务日志不记录包体                  | 日志捕获测试与源码闸门                 | 终端恶意扩展仍可能读取浏览器存储                              |
| WebSocket  | CSWSH、超大帧、连接耗尽    | 生产 Origin allowlist；64 KiB；禁压缩；20 msg/s、burst 40；全局未认证连接上限；心跳清理           | 边界和限流集成测试（M01 前完成）       | 单实例仍需上游连接/带宽限制                                   |
| 事件历史   | 篡改、部分提交、双执行     | SQLite WAL/FULL；事件/收据/版本同事务；逐事件哈希链；备份只读校验                                 | 回滚故障注入、恢复重放                 | 哈希链不防有写权限攻击者重算整链                              |
| 随机公平   | 客户端操纵或提前获知种子   | 服务端秘密种子；SHA-256 counter；事件记录 cursor/选项 hash；结束后审计披露                        | 固定种子重放与属性测试                 | 服务运营者仍可控制初始种子，云前再设计 commit/reveal 运营流程 |
| 日志       | 日志成为秘密数据库         | 禁止视图/命令正文/手牌/牌堆/种子/令牌；玩家仅使用不含昵称的引用；指标无高基数 ID                  | 日志 Schema/快照测试                   | 崩溃堆栈需检查第三方错误是否夹带输入                          |
| 服务可用性 | 慢命令、爆量房间、磁盘写满 | 固定六人；消息/连接/房间速率；Actor 队列上限；SQLite busy timeout；磁盘/队列/延迟指标             | 压测与故障矩阵（M01/M09）              | 本地 MVP 不抵御大规模分布式攻击                               |

## 在 M01 前必须实现的运行控制

当前 P08 骨架已实现首帧认证、最大帧、禁压缩、秘密日志 redaction 和无观战入口。真正开放建房前还必须实现 Origin allowlist、每 IP/连接限流、未认证连接上限、队列上限、随机 token 哈希存储和令牌重发/吊销；这些不能用“云 WAF 以后再做”代替。
