# MVP 范围与验收

## 产品范围

首个可玩版本采用以下边界：

- 固定六人；
- 标准包与“凤鸣玉誓”扩展；
- 匿名昵称与邀请码房间；
- 选角、基本回合、摸牌、出牌、伤害、濒死、救援与胜负；
- 首批迁移冰心诀、灵葫仙丹及其必要的响应/替代规则；
- PC 浏览器与手机竖屏浏览器；
- 断线重连、命令幂等、服务重启恢复；
- 基础事件日志和仅公开信息的对局记录；
- 操作时限 15 秒；可选响应超时自动放弃，强制选择超时执行可重放随机合法项；
- 断联满 60 秒后进入自动决策状态；
- 先完成本地开发和验证，再设计云端部署。

明确暂缓：

- 账号体系、好友、排位与赛季；
- 公开观战与观战视图；
- 参与正式对局的产品型机器人；
- 语音、皮肤、商城和复杂动画；
- 所有扩展包一次性迁移；
- 水平扩容和跨区域容灾。

- [ ] 资源与旧代码授权结论记录。

## 第一纵向切片验收

六名玩家能够：

1. 创建/加入同一房间并占据稳定座位；
2. 完成最小选角和开局；
3. 摸牌并使用一张产生伤害的牌；
4. 在作用前打开冰心诀响应窗口；
5. 选择抵消或全部放弃，并正确恢复原效果；
6. 伤害使角色进入濒死，其他玩家使用灵葫仙丹或放弃；
7. 在任一响应窗口断线并重连，继续看到同一选择；
8. 服务进程重启后恢复同一效果栈和窗口；
9. 重复提交、延迟提交和旧版本提交不会重复执行；
10. 六个玩家视图都不泄露无权得知的手牌。

## 非功能验收

- 360×800 与 1366×768 视口可完成整条流程；
- 常用触摸目标不小于 44×44 CSS 像素；
- 正常网络下操作反馈不依赖乐观执行隐藏规则；
- 每次规则失败可通过 `matchId + version + commandId` 追踪；
- 一局状态和事件能够离线重放到相同结果。
