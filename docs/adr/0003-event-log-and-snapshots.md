# ADR-0003：事件日志与周期快照

- 状态：P08 细化后接受
- 日期：2026-08-18

## 背景

对局需要支持掉线重连、服务重启恢复、问题审计和确定性回放。只保存最终棋盘无法恢复正在等待的嵌套响应，只保存全部事件又会使长局恢复变慢。

## 决策

每个已接受命令原子写入领域事件与新版本，并周期性保存完整可序列化快照。恢复时加载最近快照并重放后续事件。

## 后果

- 状态结构需要显式版本迁移；
- 命令必须幂等并包含预期版本；
- 能复现复杂争议和生成回放；
- 需要设计日志保留、压缩与敏感信息访问策略。

## P08 细化

- SQLite 中领域事件、`commandId` 收据、对局版本和可选快照同一事务提交；
- 事件逐局严格递增，并保存前一事件 SHA-256 哈希；
- 每 25 条已接受命令、进入玩家等待点、结束和优雅停止时保存快照；
- 数据库迁移只允许显式向前，遇到比程序新的版本拒绝启动并保留原文件；
- 恢复由纯 `reduceEvent` 从最近快照重放后续事件，不从日志或墙钟猜状态。
