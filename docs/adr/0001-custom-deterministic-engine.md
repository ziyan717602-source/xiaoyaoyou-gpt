# ADR-0001：自研确定性规则引擎

- 状态：P06 技术探针确认
- 日期：2026-08-18
- 探针确认：2026-08-19

## 背景

旧规则通过事件代码、数字优先级、递归方法与阻塞输入实现冰心诀、濒死和多人响应。结算位置主要存在于 C# 调用栈中。通用回合制框架能提供房间和阶段抽象，但本项目仍需自行实现效果身份、嵌套响应、替换、取消和持久化续算。

## 决策

实现无网络、无 UI 的确定性引擎，使用显式 `EffectStack`、`ReactionWindow` 和 `PendingChoice`。不以 boardgame.io 作为规则内核。

## 后果

- 前期必须投入状态模型和测试基础设施；
- 能精确表达复杂规则并在任意等待点恢复；
- 网络和 UI 可以独立演进；
- 房间、匹配等通用能力需要自行实现或选用更低层的库。

## P06 复核

三个不迁移真实内容的可失败探针已验证：

1. 嵌套取消可以在每个 JSON 等待点恢复；取消被反制后原伤害从保存续算点继续，并能进入濒死/救援。
2. 六个独立客户端投影只包含自己的秘密牌和私密动作；重复、过期和越权命令不重复改变状态。
3. 响应窗口快照保留绝对期限；重启后超时至多执行一次，强制选择可由固定种子重放，断联不暂停 15 秒。

结论：继续 TypeScript 自研确定性引擎路线。探针证明状态模型可行，但不等于完整规则、真实网络或持久化已经实现；这些仍由 P07/P08 和正式 MVP 节点验收。
