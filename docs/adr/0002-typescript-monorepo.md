# ADR-0002：TypeScript monorepo

- 状态：接受
- 日期：2026-08-18

## 背景

旧代码基于 .NET Framework 4.0 和 WPF。浏览器客户端必然需要 Web 技术，直接保留旧服务端仍需重写线程、网络和恢复模型。

## 决策

使用 Node.js 22、TypeScript 与 npm workspaces。规则引擎、协议、服务端和 React 客户端位于同一仓库，但保持明确包边界。

## 后果

- 协议类型可在前后端共享；
- 旧 C# 规则按场景逐步翻译而不是逐行移植；
- 必须通过包边界防止服务端私密状态意外进入客户端；
- 若未来性能测量证明需要，可保持协议不变替换特定服务实现。
