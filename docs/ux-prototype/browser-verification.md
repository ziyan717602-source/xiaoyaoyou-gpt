# P05 可见浏览器验证记录

日期：2026-08-19

验证使用本地可见浏览器和固定视口，页面为 `http://127.0.0.1:5173/`。截图不含旧项目素材、账号或真实玩家数据。

## 状态矩阵

在 `1366×768` 和 `360×800` 分别切换 11 个场景，共检查 22 个组合：自己回合、单目标、多目标、冰心诀、多人濒死、等待他人、断联、重连、过期动作、长内容和结算。

每个组合均满足：

- 场景标题与合同一致；
- 页面级横向溢出为 `false`；
- 情境操作托盘在当前视口可见；
- 所有可见 `button/select` 的宽高均不小于 44px；
- 桌面页面高度为 768px；手机除断联/重连提示可纵向滚动 27–37px 外，其余为 800px；
- 长内容场景的 14 张手牌保持局部横滑，确认区不被推走；
- 等待、断联、重连、过期和结算场景没有可用手牌动作。

## 操作轨迹

1. 自己回合选择【灵力爆发】；五名其他角色出现“可选目标”，确认按钮保持禁用。
2. 选择柳梦璃；确认按钮启用；确认后得到 `使用灵力爆发 → 柳梦璃` 的原型命令回执。
3. 多目标场景选择【妙手回春】，依次点李逍遥、柳梦璃和景天；达到上限后第三次点击不进入集合，屏幕保持两名已选目标。
4. 按 Escape 后未提交卡牌和目标全部清空；Tab 焦点有实线轮廓。
5. 冰心诀场景只有【冰心诀】、`本次放弃` 与确认可用；效果链明确原效果、等待响应和取消动作。
6. 多人濒死场景只允许选择当前救援对象景天，赵灵儿显示为排队对象；手机确认托盘固定在安全区上方。
7. 过期场景可用手牌数为 0，旧操作不能提交。
8. 修复热更新根节点后连续两次刷新没有新增控制台 error；旧会话中修复前的历史错误不作为当前结果。
