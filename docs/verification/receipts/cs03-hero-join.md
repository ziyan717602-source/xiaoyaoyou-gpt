## 失败与反向复核

1. 初始新增契约测试因不存在角色加入模块为红；另用真实 JN20602 结算保留直接行为失败：预期 STR 9/DEX 5，旧结果为 8/2。修复后同场景变绿。
2. 首轮新增手牌上限测试误把 JN50402 配给 XJ504。核对 `setup-content.ts` 与已映射目录，修正为实际角色 XJ404，仍要求上限 5，没有放宽断言。
3. 复核 `XIG.cs:1249-1263`：全弃分支不洗牌，因此 NJ01 手动支付不额外消耗 RNG；保留原手牌顺序。
4. 复核 `Player.cs:264-361` 和 `XIG.cs`：重置的是换角者的角色状态，不应清除他人的回合使用记录；物理装备和宠物保留，失效原因不应随角色身份消失。
5. 角色历史引用与物理分区分开；不把死者角色引用强行清空，不伪造旧 v10 没有记录的弃置历史。未迁移 token/ROM/受保护牌/宠物封印生产者不被当作无效果完成。
