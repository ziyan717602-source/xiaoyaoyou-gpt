## 已验证边界

- 当前玩家独占支援/放弃决定；基础支援项包含自己和全部存活同队玩家，其他五份视图不获得该动作。
- 对应敌方按两队 `turnIndex` 序号匹配；对应者死亡时向后寻找并回绕。该存活敌方独占妨碍决定，妨碍候选为全部存活敌方。
- 支援和妨碍分别使用独立 15 秒绝对期限；系统超时固定为放弃和 pass，提前触发超时被拒绝。
- 参与者使用 `player`、`pet`、`special` 三种带标签引用；宠物/特殊牌只可作为规则钩子追加的参战项，不获得决定权。
- 放弃从主堆移除恰好一张并追加至公开弃牌；战斗揭牌从主堆移除并由 `revealedCardId` 持有，牌实体守恒。
- 阶段、决定者、候选、参与者、期限和揭牌均可 JSON 往返；过期、异队、非法候选和重复决定均被拒绝。
- 当前正式回合仍保持 M03 的 encounter/battle 跳过，不向玩家开放无法完整结算的战斗路径。
