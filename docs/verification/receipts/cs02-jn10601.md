## 已验证边界

- 只有原生 XJ106 酒剑仙应用该锁定技。空武器槽首次装备后，权威 `dexterity` 从基础 1 变为 2；普通英雄不获得此修正，`strength` 不受影响。
- JN10601 与 JN10401 共用一个确定性武器占用差值函数。正常装备、替换、WQ04 典当、JN50401 赠剑、JP06 弃置装备、普通死亡清区和 JN50203 盗墓收取不会形成不同规则分支。
- 单武器槽替换是 `1→1`，不叠加命中；防具变化是 `0` 差值，也不改变命中。武器导出恢复基础命中，卡牌实体继续守恒。
- `dexterity` 作为公开战斗属性进入六份玩家投影。技能没有主动命令、选择、响应或超时，也不会通过动作集合暴露私密能力。
- 单元测试覆盖普通英雄、首次装备、换武器、防具、典当和公开投影；此前同一共享函数的赠剑、铜钱镖和两种死亡清区分支继续由 JN10401 场景锁定。
- JSON 测试在装备与典当后分别恢复并逐事件归约。六个真实 WebSocket 先验证 XJ104 武器替换不叠加，再让 XJ106 从空槽接收武器而命中 `1→2`，最后在 SQLite 重启后验证装备、命中、目标记忆和六张私有补牌均一致。
