- JSON 重启测试覆盖原绝对截止、事件逐条重放和字节等价状态。真实六 WebSocket + 临时 SQLite 覆盖实际断线、60 秒等价夹具、自动座位立即回退、认证后私密视图、优雅停服保存六个 grace 代次、停机期间到期首次启动只结算一次、再次启动不重复。

## 失败先行记录

- 首次网络用例暴露认证消息与初始 `player-view` 可以合法乱序到达；修复客户端测试辅助函数，使两者都到达后才完成连接，未放宽规则断言。
- 实际 WebSocket 关闭回调与测试注入的老断线代次发生竞态；改为先等待公开 `grace`，再刷新同一玩家的断线代次，继续验证真实断线链路。
- 审计发现优雅停服若只关闭传输层，会把 60 秒起点推迟到下一次启动；服务端现于关闭数据库前通过同一系统命令管线持久化仍在线座位，并新增六席 grace 与六个可重建自动截止断言。
- 最终并发审计发现六席同时认证可能都读取同一旧版本，导致第一个 presence 成功而其余被 Actor 判为 stale；服务层现只对系统命令使用最新 Actor 版本重新排队，玩家旧版本仍严格拒绝，并在两次真实重启后逐席断言私密视图发出前均已 connected。
- 旧 M02/M03/M04 合同检查器和精确对象断言引用了重构前的函数名或 Schema v4 形状；更新为当前可注入权威时钟、通用命令散列和明确的 v5 时间字段，保留原幂等、回放与阶段断言。
