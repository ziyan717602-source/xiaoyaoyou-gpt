# P04 语义场景矩阵

机器合同为每个场景给出稳定 ID；`npm run semantics:verify` 检查覆盖标签和关键反例。P02 三条旧版轨迹提供基本回合、冰心诀和多人濒死的来源基线。

| ID        | 分支               | 预期                                                       |
| --------- | ------------------ | ---------------------------------------------------------- |
| `SEM-S01` | 正常生命周期       | 基本回合完成并进入下一存活座位                             |
| `SEM-S02` | 响应窗全员放弃     | 连续放弃关闭窗口，父效果只结算一次                         |
| `SEM-S03` | 嵌套反制           | 第二个取消命中第一个取消；原效果恢复为 pending，不重复成本 |
| `SEM-S04` | 伤害替换/加成/减免 | 按固定优先级处理，整批应用后才检测濒死                     |
| `SEM-S05` | 单人濒死获救       | HP 大于 0，取消死亡并重检队列                              |
| `SEM-S06` | 多人同时濒死       | 按座位快照逐目标打开救援，前一目标完成后再处理下一人       |
| `SEM-S07` | 可放弃动作超时     | 15 秒生成一次 `TimeoutPass`                                |
| `SEM-S08` | 强制动作超时       | 稳定选项排序 + SHA-256 拒绝采样，记录结果和 cursor 范围    |
| `SEM-S09` | 操作中断联         | 15 秒继续走；60 秒后座位进入自动模式                       |
| `SEM-S10` | 窗口期间服务重启   | 恢复绝对截止时间；已过期只追加一个幂等超时                 |
| `SEM-S11` | 无目标/目标消失    | 不提供动作，或接受后产生显式 fizzled 事件                  |
| `SEM-S12` | 重复/过期/越权     | 不追加领域事件，返回稳定拒绝或首次幂等结果                 |
| `SEM-S13` | 六人私密视图       | 每个玩家只见自己手牌，其他人只有数量                       |
| `SEM-S14` | 同时团灭           | 完成死亡后效果与重算后判平局                               |

后续新引擎测试必须使用这些 ID；若拆成更细场景，保留父 ID 作为 tag，保证准备阶段合同不会在实现中失联。
