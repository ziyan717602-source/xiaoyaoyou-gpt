# P04 不变量

每次接受命令、重放事件和恢复快照后都必须满足：

1. 准备检查之后始终恰有六个稳定座位。
2. 每个 match 只有一个权威状态和严格递增版本。
3. 同一时刻至多一个顶层玩家等待窗口。
4. 开放窗口必有一个可序列化续算点和绝对截止时间。
5. effect/window/choice/event ID 永不复用。
6. HP 与手牌数量不为负；0 HP 存活与死亡是两个不同状态。
7. 死亡玩家默认不在响应/救援资格中，明确 after-death 效果除外。
8. 每个伤害批次完整应用后才打开濒死队列。
9. 每个接受的 commandId 只有一个稳定幂等结果。
10. 未授权视图不含他人手牌 ID、私密选项或稳定替代标识。
11. 随机结果总能定位 seed、cursor 范围和候选集合哈希。
12. 快照加后续事件重放结果与原状态逐字节等价。
13. finished 状态不能再接受游戏命令。
14. 超时、断联和重启产生的系统命令与玩家命令走同一验证/事件管线。
15. 规则实现不得根据对象地址、线程时序、系统随机或未排序集合改变结果。

违反不变量必须拒绝写入并保留诊断证据，禁止“尽量修正后继续”。
