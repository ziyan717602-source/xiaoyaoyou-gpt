# P04 临时规则决定

这些决定用于解除实现歧义；如果之后发现更高等级 C#/规则证据，必须用新决策记录替换，不能只改代码。

| ID        | 状态                   | 决定                                                                            | 理由                                                                |
| --------- | ---------------------- | ------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| `SEM-001` | provisional-autonomous | 15 秒操作计时在断联时继续；60 秒只控制座位进入自动模式                          | 否则一次掉线可把每个响应窗拖到 60 秒，违背已确认的 15 秒操作上限    |
| `SEM-002` | provisional-autonomous | 强制选择超时先排序合法 ID，再由 SHA-256 计数器 RNG 拒绝采样；可放弃动作直接放弃 | 对应用户给出的“能放弃默认放弃，不能放弃随机”，且可重放、无取模偏差  |
| `SEM-003` | provisional-autonomous | 同一死亡周期后双方都没有存活角色判平局                                          | 旧实现存在 `G0WN,0`，新引擎必须给 0 明确稳定含义                    |
| `SEM-004` | provisional-autonomous | 取消效果被反制后，父效果从保存续算点恢复，优先权从子效果来源下一座位重开        | 防止父效果丢失、重复支付或回到错误栈位置                            |
| `SEM-005` | provisional-autonomous | 无目标动作不提供；接受后目标消失则显式 fizzled，默认不退成本                    | 区分客户端旧视图与规则无目标，保证事件可审计                        |
| `SEM-006` | provisional-autonomous | 队友不能看彼此手牌，只能看已声明的队内信息                                      | 六人在线的隐私边界应默认最小授权，旧 TCP 的 Focus/Live 也区分接收者 |
| `SEM-007` | provisional-autonomous | 房间座位永久稳定；种子另行洗出回合顺序，奇偶回合位组成 3v3，首位先手            | 保留 M01 重连身份，同时等价表达 C# 随机 UID、奇偶分队和 UID 1 先手  |

没有保持 `open` 的规则问题；以上均可在无人值守开发中执行。用户若否决其中任何一项，先改合同、场景和收据，再改实现。
