## 非阻塞风险

1. 旧服务端未形成稳定全自动黑盒整局，黄金轨迹为源码+SQLite+协议一致的 grade B；正式内容必须继续逐项绑定证据。
2. 当前六人本地环境和房间旅程是明确标记的验证 fixture，不是 M01 产品房间。
3. Origin allowlist、速率/队列上限、随机重连 token 哈希与吊销必须在 M01 开放入口前实现。
4. SQLite 只允许单实例和持久卷；多实例/无持久卷云平台会触发 PostgreSQL+租约 ADR，不能直接横向扩容。
5. P07 独立集成夹具仍使用实验性 `node:sqlite` 并输出 warning；生产代码已固定 `better-sqlite3`。
6. 卡图、音乐、字体和旧 DLL 未获再分发授权，继续不进入公开历史；最终美术不阻塞规则 MVP。
7. `/goal pause/resume` 是维护者侧控制，代理按产品权限不能自行暂停；持续执行、状态和最终完成闸门已由当前真实目标验证。
